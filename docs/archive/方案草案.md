# 大学生课程学习辅助软件 · 方案草案

> 版本：v1（2026-08-31）
> 状态：草案，待用户确认后进入开发

## 1. 产品定位

面向**大三在校生**的个人学习工作台：把教材、课件、题库等资料统一收进本地知识库，提供**自学、复习、刷题、期末冲刺**全流程辅助。数据与 AI 能力本地运行，**教材内容作为权威依据**，杜绝 AI 胡编乱造。

## 2. 目标用户与课程

- 用户：大三在校生（自主学习者）
- 首批 4 门课：
  - 《计算机网络》第八版（谢希仁）
  - 《UML2 面向对象分析与设计》第二版（谭火彬，清华大学出版社）
  - 《软件工程导论》（薛继伟主编）
  - 《算法设计与分析》第三版

## 3. 系统架构（三层，UI 可替换）

```
表现层    PySide6 UI（先核心后美化，接口固定可整体替换）
   ↓ 固定接口
服务层    自学 / 刷题 / 期末冲刺 / 资料管理 / 检索
   ↓
核心引擎  文档转换管线 · 知识库 · 向量检索 · 错题本
```

- 分层目的：UI 与引擎解耦，将来美化界面或换 Web 前端，引擎零改动。
- 打包：PyInstaller → 单 exe，本机运行。

## 4. 功能模块（按优先级）

| 模块 | 内容 | 优先级 |
|---|---|---|
| 资料管理 | ① 教材库（PDF→Markdown 入库、检索浏览）② 课件归档（老师发的 PPT/PDF/Word 拖入自动转格式入库）③ Word 版教材批注（生成 .docx 交由 Word/WPS 批注，软件归档） | 核心 |
| 课前课后自学 | 知识树/大纲（按教材章节拆知识点）；知识点讲解（基于教材内容回答，必要时联网补充） | 最高 |
| 刷题备考 | 题库联网检索**高校历年期末真题**（半自动：列候选+标注来源→用户确认入库；拒收 AI 生成/来历不明题）；支持导入自有题库；按选择/填空/大题**分科成文档**；按章节刷 + 随机组卷 | 高 |
| 期末冲刺 | 复习提纲生成（提炼重点易考点）+ 错题重刷 + 进度看板 | 中 |
| 错题本 | 与刷题联动：答错自动入本；循环出题，用户选对→移出，选错→保留继续循环 | 中 |
| 答疑 | **预留位**（底座待定） | 待办 |
| 课程同步 | **预留位**（手动课表 + 周计划，后续按需加） | 待办 |
| 移动端 | **预留位**（后续考虑） | 待办 |

## 5. 数据组织（关键约定）

- **教材知识库与题库物理分离**：独立存储、独立检索，互不混放。
- 教材：PDF → Markdown 章节化 → 向量化入库（RAG）。
- 题库：按科目分文档（选择/填空/大题分区），来源可溯源。
- 错题本、批注文件：独立目录。
- 预留位：`reserved/ai_assistant/`（答疑）、`reserved/course_sync/`（课程同步）、`reserved/mobile/`（移动端）——后续添加模块直接落位，无需重构。

## 6. 开发路线图

1. 引擎层：文档转换管线（PDF/PPT/Word→Markdown）→ 教材入库 + 向量检索
2. 服务层：自学 → 刷题（检索/章节刷/组卷）→ 错题本 → 期末冲刺
3. UI 层：朴素界面串联 → 打包 exe 自测
4. 预留：答疑、课程同步、移动端
