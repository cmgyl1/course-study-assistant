# 工具安装清单

> 版本：v1（2026-08-31）
> 原则：**所有工具装入 `大学生软件/` 文件夹内，不占用 C 盘**。

## 1. 总览

| # | 工具/库 | 用途 | 是否下载 | 占用空间 | 安装位置 |
|---|---|---|---|---|---|
| 1 | Python 3.12 | 运行时 | ✅ 下载安装包 | ~120 MB（含 pip） | `tools/Python/` |
| 2 | pip 依赖（PySide6 等） | UI/功能库 | ✅ pip 安装 | ~600 MB | `tools/pylibs/` |
| 3 | pandoc | 文档格式互转（PDF/MD/Word） | ✅ 下载便携版 | ~100 MB | `tools/pandoc/` |
| 4 | LibreOffice（便携版） | Office 文档 → PDF/Markdown 转换引擎 | ✅ 下载 | ~1 GB | `tools/LibreOffice/` |
| 5 | PyMuPDF | PDF 解析 | ✅ pip 安装 | ~40 MB | `tools/pylibs/` |
| 6 | markitdown | Office/PDF → Markdown | ✅ pip 安装 | ~60 MB | `tools/pylibs/` |
| 7 | ChromaDB | 向量数据库（教材知识库） | ✅ pip 安装 | ~80 MB | `tools/pylibs/` |
| 8 | PyInstaller | 打包 exe | ✅ pip 安装 | ~30 MB | `tools/pylibs/` |
| 9 | SQLite | 本地数据库 | Python 内置 | 0 | — |

**合计：约 2 GB（全部在项目内，不占 C 盘）。**

## 2. 依赖详情

### pip 依赖清单（装进 `tools/pylibs/`）
```
PySide6            # UI 框架（~500 MB）
PyMuPDF            # PDF 解析
markitdown         # Office/PDF → Markdown（微软开源）
chromadb           # 向量数据库（RAG 检索）
requests           # 网络检索（题库搜索）
python-docx        # Word 教材生成与批注读取
pypandoc           # pandoc 的 Python 封装
pyinstaller        # 打包 exe
```

### 独立工具
- **pandoc**：下载 Windows 便携 zip，解压到 `tools/pandoc/`，免安装。
- **LibreOffice**：下载**便携版**（PortableApps 版），解压到 `tools/LibreOffice/`，免安装；用于把老师发的 PPT/DOCX 转成可解析格式。

## 3. 环境变量设置（安装完成后）

```
PYTHONPATH     = D:/atomcode/大学生软件/tools/pylibs
```

## 4. 安装顺序

1. Python 3.12 → `tools/Python/`（安装器勾选自定义路径）
2. `tools/Python/python.exe -m pip install -r requirements.txt`（依赖装到 `tools/pylibs/`）
3. pandoc 便携版解压到 `tools/pandoc/`
4. LibreOffice 便携版解压到 `tools/LibreOffice/`

## 5. 备注

- 所有下载安装包统一放 `tools/downloads/`，装完可删。
- 本机无 Python 时需先装；若已有 Python 3.10+ 可直接复用（仍建议统一到项目内，保证可移植）。
