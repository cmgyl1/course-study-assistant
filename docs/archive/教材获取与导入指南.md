# 教材获取与导入指南

> 目的：把 4 门课的教材内容安全、合法地导入本地知识库，作为软件的权威资料依据。

## 1. 核心原则

**软件只接受合法获取的教材内容。** 网上流传的整本教材 PDF 绝大多数是盗版，
我们不下载、不收录盗版副本——这也保护你自身（学习资料私有、合法）。

合法来源有 3 类：
1. **你已经合法拥有的教材**（实体书扫描件 / 学校发放的电子版 / 购买的正版电子书）
2. **出版社官方配套资源**（课件 PPT、试读章节——见 §3）
3. **高校教学平台公开共享的官方课件**（教师公开的讲义）

## 2. 一键导入流程（推荐）

1. 把你拥有的教材 PDF / 电子版放到文件夹：
   ```
   D:/atomcode/大学生软件/data/textbooks/
   ```
   （文件名建议包含课程名，便于自动归类，例如 `计算机网络第8版-谢希仁.pdf`）

2. 运行一键导入脚本：
   ```
   D:/atomcode/大学生软件/tools/Python/python.exe D:/atomcode/大学生软件/tools/import_textbooks.py
   ```
   或指定课程：
   ```
   ... import_textbooks.py --course 计算机网络
   ```

3. 脚本会自动：PDF → Markdown → 分块入库（向量化）→ 生成 Word 版教材（供批注）。
4. 打开软件 →「自学」页 → 刷新知识树即可看到教材章节。

> 也可以在软件「资料管理」页直接点“选择教材 PDF 并转换入库”，效果相同。

## 4. 官方课件（PPT）如何入库

课件也是很好的学习资料。方法：
- 下载官方 PPT 后，直接放入 `data/textbooks/`（文件名含课程名），
  运行导入脚本即可（脚本支持 pptx/ppt）。
- 或放入软件「资料管理 → 课件归档」，按课程自动归档为 Markdown。

## 5. 常见问题

- **Q：我没有电子版，只有纸质书？**
  A：你可以扫描成 PDF（手机扫描 App 即可）放入 `data/textbooks/`；
  或购买正版电子书（文泉书局/微信读书，价格通常低于纸书）。
- **Q：扫描版 PDF 文字提取不全？**
  A：清晰扫描件一般可提取；若为图片型扫描件，导入时会提示“无可提取文本”，
  需要先用 OCR 工具转成可复制文本的 PDF（如 Adobe Scan / 全能扫描王）。
- **Q：为什么不在软件里直接联网下载教材？**
  A：整本教材的免费电子版基本都是盗版。软件坚持“权威资料合法化”，
  这是产品价值观，也避免你承担法律风险。
